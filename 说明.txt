PCL LCP 修改版（LCP Edition）2.15.1
=====================================================

重要声明
--------
本软件是第三方基于 Plain Craft Launcher（PCL）独立进行的二次创作修改版，
并非 PCL 官方发布，与 PCL 官方及 PCL 社区版官方均无隶属关系。
原作者：龙腾猫跃（赞助：https://afdian.com/a/LTCat）

这是什么
--------
PCL 社区版（PCL2 CE）v2.15.1 / build 524 的源码重新编译，界面与功能保持原版结构，
品牌标识已替换为 LCP（LCP Edition）。

本版改动
--------
1) 品牌替换：窗口/文件图标、标题栏字标、关于页头像、启动画面 Logo 均替换为 LCP；窗口标题显示为 LCP。
2) 正版登录：补上微软 OAuth 客户端 ID 回退，不再报 Microsoft OAuth client id is not configured。
3) 联机大厅：补上 LINK_SERVER_ROOT 回退，不再报无法连接到大厅服务器。
4) 大厅 Natayark 登录：授权与换 token 都使用官方内置的 pclce2025 客户端，不再 401 / invalid_request。
5) 解除地区限制：原版下载、版本补全/修复、整合包安装、加载器安装不再弹「地区不可用」。
6) 离线验证入口默认可用。
7) 更新源改为 Naids 优先；被墙源的连接失败只记 WARN，不再弹红色提示。

怎么用
------
1.双击 PCL-LCP-Edition_2.15.1_x64.exe（要装上 .NET 10）。
2. 左侧「登录」→ 正版验证 → 点「登录」，弹窗显示设备代码并打开
   https://www.microsoft.com/link，输入代码、微软账号授权即可。
3. 工具 → 联机 → 大厅：公告正常、可创建/加入大厅。
4. 选实例 → 启动；缺客户端文件时会先自动补全再启动。

数据与实例
----------
- 账号、档案、皮肤数据在 %APPDATA%\PCLCE。
- 游戏目录指向 D:\project\pcl2复刻\.minecraft（本地配置已写好绝对路径）。
- 与「内置版」共用单例锁，不能同时开。

运行环境
--------
需要 .NET 10 Desktop Runtime（x64），本机已装 10.0.15。
新机器可直接运行本目录下的 windowsdesktop-runtime-10.0.15-win-x64.exe 安装，
或下载：https://dotnet.microsoft.com/download/dotnet/10.0
